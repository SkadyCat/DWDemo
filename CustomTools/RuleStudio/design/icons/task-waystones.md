# 图标任务：路石 & 星契

现在所有路石共用 `misc/waystone`，只靠角标数字和边框颜色区分；星契全是同一个星形。这批图让它们一眼可分：

- **路石 12 张** = 4 个阶段（形状逐级升级）× 3 种稀有度（光色：灰 / 蓝 / 金）
- **星契 7 张** = 每种一张（主色和图案不同；黯淡 / 明亮 / 辉煌三阶在游戏里用光晕区分）

规格同 `icon-prompts.json`：512×512，painted 风格，深蓝底。生成后按 `file` 列放好，运行 `python3 scripts/build-icons.py`，游戏自动换上（缺的图继续用旧图标）。
