# 世界循环：为什么要刷、刷来干什么

所有资源最后都回到一件事上：**变强**。变强要点天赋，点天赋要钱和地区物资，钱和物资要靠自己刷、靠佣兵带、靠势力委托换。

```
刷图 ──掉落──► 星银 + 地区物资 + 装备 + 路石
  ▲                               │
  │          ┌────────────────────┼─────────────────────┐
  │          ▼                    ▼                     ▼
  │     点天赋（星银 + 物资）   雇佣兵出征（星银 + 装备）  接势力委托
  │          │                    │                     │
  │          │              带回物资 / 可能会死           声望 → 折扣、商品、更强的佣兵
  │          ▼                    ▼                     │
  └──── 更强 → 能打更高阶 → 更高阶的物资更值钱 ◄──────────────┘
```

代码：`public/game/economy.mjs`（星银、物资、天赋花费、商会价格）、`factions.mjs`（势力、声望、委托）、`mercs.mjs`（佣兵）。
数值曲线可以用 `node scripts/sim/economy-curve.mjs` 模拟。

---

## 1. 星银和地区物资

星银和物资都不占背包格子，在地上走过去就自动捡起。背包顶上有一行钱包。

| 物资 | 来自 | 天赋盘上用在 |
|---|---|---|
| 余烬铁心 | 余烬之域 | 焰域 |
| 霜晶 | 霜原之域 | 霜域 |
| 雷鸣铜 | 雷暴之域 | 雷域 |
| 孢核 | 腐沼之域 | 毒域 |
| 王都残金 | 废墟之域 | 刃域 |
| 星砂 | 哪儿都有一点 | 中圈和风域 |
| 星尘 | 只有首领掉（T3 起，约四成） | 基石 |

五种地区物资各分三档：**粗**（T1–5 的图掉）、**精**（T6–10）、**纯**（T11–16）。天赋点得越多，要的档位越高，所以不能一直待在低阶图。商会可以把 4 份低档精炼成 1 份高一档。

### 一张图大概给多少

`mapIncome(T) = 60 × T^1.25`，实际掉落约为它的 1.15 倍，另外加上卖装备的收入。

| 阶 | 星银（大约） | 本地区物资 |
|---|---|---|
| T1 | 70 | 3–5 份粗 |
| T5 | 500 | 4–6 份粗 |
| T7 | 800（实测一张 T7 雷暴图：958 星银、7 份精雷鸣铜、3 份星砂） | 5–8 份精 |
| T10 | 1200 | 6–9 份精 |
| T16 | 2300 | 7–10 份纯 |

掉落的分布：首领 35% 的星银加 3+T/4 份物资；精英 60% 机会掉一小笔星银、20% 机会掉 1 份物资；普通怪 8% 机会掉零钱、1% 机会掉 1 份物资。

## 2. 天赋：主要的花钱地方

- **点数是资格**，还是打通图集节点获得：普通节点 +1，首领要塞 +2。
- **点亮要花星银和物资**，花多少取决于这是你的第几点（n）：
  - 星银 = 80 × 1.045ⁿ × 种类系数（小点 1，大点和特性 1.6，基石 3）。
  - 物资 = (1 + ⌊n/12⌋) × 种类系数份。用天赋所在域对应的地区物资；n < 30 用粗，30–74 用精，75 起用纯。中圈和风域用星砂。
  - 基石另外要 3 份星尘，桥上的混合基石要 5 份。
- **取消返还六成**（星银和物资都是），全部重置也一样。
- 法师学会的声望能打折：每升一档便宜 5%，最多便宜 20%。

| 第几点 | 小点星银 | 物资 |
|---|---|---|
| 1 | 80 | 1 份粗 |
| 20 | 193 | 2 份粗 |
| 50 | 722 | 5 份精 |
| 80 | 2700 | 7 份纯 |
| 110 | 10000 | 10 份纯 |

**模拟结果**（`scripts/sim/economy-curve.mjs`：140 张图，大约每 7 张升一阶）：

- 前 50 张图，点数和花费差不多同步，有点就能点。
- 从第 60 张图起开始「有点数没钱」：第 100 张图时有 116 点，只点得起 90 点。
- 派佣兵能多出大约 10 点。这就是想要的压力：后期必须用上佣兵、委托和跑商。

## 3. 商会（集市街南头）

- 收购和出售所有物资。价格跟着库存走：你卖得越多，收购价越低；买得越多，出售价越高。每打完一张图，库存回落五分之一。
- 卖装备：背包里右键「卖给商会」，或者在商会一键卖掉所有普通、魔法装备。
  - 价格 = (底价 + 每阶加价 × 物品阶) × (1 + 0.5 × (基底词条数 − 1))。
  - 底价和每阶加价按稀有度：普通 2+1，魔法 5+2，稀有 12+4，传世 30+8，传奇 80+12。
- 精炼：4 份换 1 份高一档的，收一点手续费（商会声望到「信任」免手续费）。

## 4. 势力和委托（灯井广场的布告板）

| 势力 | 谁 | 委托 | 声望的好处（认识 / 信任 / 尊敬 / 崇敬） |
|---|---|---|---|
| 冒险者公会 | 玛蒂 · 半盏灯 | 讨伐某个地区 T 阶以上的首领 | 一开始就能雇铜牌 → 出征费 −10% → 银牌 → 金牌 → 出征费 −25% |
| 法师学会 | 伊芙 · 观星阁 | 穿过试炼 / 宝库 / 腐化地图 | 天赋 −5% / −10% / −15% / −20% |
| 商会 | 集市街 | 交一批物资 | 买卖价格优惠 5% / 10%（加免精炼费）/ 15% / 20% |
| 守灯会 | 诺娅 · 金殿 | 交一块 T 阶以上的路石 | 多给一枚星契 / 物品数量 +5% / +10% / +15% |
| 拾荒队 | 格雷 · 酒馆后院 | 在某个地区打通 3 张图 | 地区物资掉落 +10% / +20% / +30% / +40% |

- 声望档位：陌生 0，认识 100，信任 400，尊敬 1200，崇敬 3000。一个委托给 50–70 声望。
- 布告板同时贴 5 个委托，一次最多接 3 个。每打完 3 张图，没人接的那批换掉。委托的阶数按你目前能开的最高阶往下浮动 0–2 阶。
- 打图类委托自动计数；交货类委托在布告板上交。
- 奖励：星银是那个阶数一张图收入的 0.8–2.2 倍，外加声望，有的还给物资或星契。

## 5. 佣兵（半盏灯酒馆门口的冒险者公会）

- 登记的人是镇上没有名字的镇民，有自己的名字、等级和流派。分三档：
  - 铜牌：1–4 级，雇佣费 150。
  - 银牌：6–10 级，雇佣费 1800。
  - 金牌：12–16 级，雇佣费 14000。
- **实力** = 等级 + 0.5 × 你给他的最好那件装备的阶数。背包里用不上的装备，现在有地方用了。
- **派出征**：选一个你到过、阶数不超过你能开的最高阶的节点，付出征费（这一阶一张图收入的 35%）。
  - 计时：你自己打完 2 张图（T1–5）、3 张（T6–10）或 4 张（T11–16）之后，他回来。按图数计时，不按现实时间，所以不会变成挂机游戏。
  - 成功率 = 62% + 9% × (实力 − 节点阶数)，限制在 10%–96% 之间。
  - 成功：带回这一阶一张图收入 90% 的星银、4 + T/3 份本地区物资（拾荒队声望另有加成）、1–2 份星砂，升一级。
  - 失败：45% 的机会死掉（装备一起没了，名字留在「没回来的人」里），否则养伤，休息 1 张图。
- 佣兵拿不到星尘。基石要的星尘只能你自己去打首领。

## 6. 节奏

| 时间 | 你在做什么 | 得到什么 |
|---|---|---|
| 半分钟到 3 分钟 | 杀怪、捡东西 | 掉落 |
| 一张图（3–5 分钟） | 打完首领 | 星银、地区物资、路石，可能有星尘 |
| 回城一趟 | 点天赋、卖东西、接委托、派佣兵、交货 | 变强一点，订好下一趟的计划 |
| 一个阶段 | 基石、势力升档、新阶数、新地区 | 打法改变 |

## 7. 防坑

- **挂机化**：出征按你打的图数计时；佣兵拿不到星尘。
- **通货膨胀**：天赋花费按 1.045ⁿ 涨，比收入涨得快；佣兵雇佣费、高阶物资和路石也在消耗星银。
- **刷错地区不白刷**：每张图都给星银；不对路的物资可以卖给商会，换成需要的那种。

## 8. 引导

三条引导支线，带玩家把新系统用一遍：
- 商会柜台「换成星银」：卖一件装备。
- 布鲁「布告板」：接下一个委托并做完。
- 玛蒂「雇个帮手」：雇一个佣兵，派他出征。
