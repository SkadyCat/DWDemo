# 旋风·风暴群：镜像与回响

2026-10-25，Opus Studio 5291。入口：[旋风·风暴群](http://127.0.0.1:5291/?bd=whirlwind_swarm)，四色地面版：[旋风·四色染地](http://127.0.0.1:5291/?bd=whirlwind_grounds)。

## 当前机制

已移除旧的定时旋风组合 interval_whirlwind。旧背包物品加载时只清除这条退休词条，保留物品与其他合法词条；新预设使用新实例ID，重新应用能得到当前配装。

1. 第一个技能槽手动施放旋风，聚合创建旋风、游走、接触地面与染色。基础1枚加两条数量各+2，一次5枚，速度27米/秒，寿命8秒。
2. 头盔命中触发镜像地面。带接触地面能力的投射物实际进入时复制一枚，包括复制体；驻留不重触发，必须退出再进入。高速穿过也算进入，高于地面的投射物不触发。
3. 复制保留伤害、元素、速度、抛物线参数、接触能力和已经经过的年龄，不刷新寿命。每枚镜像载体保留正常施法的独立命中预算；不使用触发根绕过同批结算。
4. 项链授予第二槽主动回响，独立冷却5秒，施加持续5秒的回响状态。下一次手动施放其他技能，先 consume_status 再 repeat_skill，额外执行一次完整技能。旋风因此先产生10枚。回响再次施放只刷新自身；复施不付第二份资源，不算手动输入，不会再次复施。
5. 没有输入时不会产生旋风。镜像不续命，场上最后一枚消失后需要重新施放；没有宣称永久循环。

## 配装

九件合法装备共44条随机词条：七件稀有各6条，戒指与项链魔法各1条。数值均经过T1–T10校验，装备T10，部位池有效。

| 部位 | 核心 |
| --- | --- |
| 武器、手套 | 投射物数量、物理与投射增伤、气血附加物理点伤 |
| 头盔 | 镜像地面、投射增伤、命中回复、气血伤害联动 |
| 副手 | 投射与物理增伤、命中回复、再生 |
| 衣服、鞋、腰带 | 气血、气血增幅、再生、护甲与抗性 |
| 戒指 | 环形发射 |
| 项链 | 授予回响 |

四色版保留镜像，再加入四种元素地面，伤害与异常由真实地面结算。染色只改外观，不附送元素转化或伤害。

## 当前实验

种子18、60Hz、无敌关闭、自动施法关闭。一次手动施放，20个静止高血靶位于3–11米，四元素抗性20%。镜像增长可到现有1200个战斗载体容量上限，原始施放的8秒寿命结束后全部消失。移除镜像词条后峰值仅5枚；空场没有命中便没有镜像；无输入30秒零旋风。

先回响再旋风，两次手动输入产生两次完整旋风执行，初始共10枚，只消耗一次回响状态。回响和旋风有各自的冷却，切换不会重置或串用冷却。

真实模拟数据：G:/DungeonWorldOpus/Saved/WhirlwindResearch/mirror-echo-results.json。旧 swarm-results.json 是已退休定时方案的历史数据，不代表当前行为。复现实验：node scripts/research-whirlwind-swarm.mjs <输出JSON路径>。

持续旋风表现保留既有48个容量，超过时不绘制全部载体；战斗仍由真实载体结算。地面使用单批实例化表现。Node模拟耗时不代表浏览器帧率。

针对性测试：tests/mirror-echo.test.mjs、tests/ground-fields.test.mjs、tests/whirlwind-swarm-bd.test.mjs。覆盖真实状态层数消耗、异常运行时同步、回响完整复施与冷却、镜像进出和出生边界、寿命与高速扫掠、装备池和旧词条清理。
