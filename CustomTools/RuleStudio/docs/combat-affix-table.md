## 1 统一术语与计算规则

### 1.1 数值写法

| 写法 | 含义 | 示例 |
| --- | --- | --- |
| +n点 | 增加固定数值 | 基础气血 +100点 |
| +n% | 普通相对增幅，同一作用层级加减汇总 | 气血上限 +20% |
| 额外提高 n% | 独立倍率，与普通增幅分开计算 | 伤害额外提高 20% |
| 额外降低 n% | 独立降低倍率 | 伤害额外降低 20% |
| +n个百分点 | 概率或比例直接增加 | 格挡率从20%增加至25%，是增加5个百分点 |
| +n次或+n个 | 增加离散数量 | 投射物数量 +1个 |
| n%作为额外伤害 | 根据明确的来源伤害获得另一份伤害 | 获得相当于物理伤害20%的额外闪电伤害 |
| n%转化为另一类型 | 将来源中的一部分转走 | 物理伤害的20%转化为火焰伤害 |

每个 n 都是独立参数占位符。同一条词缀出现多个 n，不表示必须取相同值；配置时应分别命名。

“暴击率 +n%”表示对基础暴击率的相对增幅；“暴击率 +n个百分点”表示直接增加概率。两种写法不能混用。“额外提高”用于倍率，“获得额外某类型伤害”用于新增伤害组成，二者不是同一种属性。

### 1.2 固定值与增幅层级

- 基础数值先与适用的固定值相加，再应用同层级普通增幅，最后应用独立倍率。
- 装备局部增幅只作用于该装备对应的基础数值；角色全局增幅作用于符合条件的角色属性。
- 特定装备来源增幅，只作用于指定来源，例如头盔提供的护盾。
- 继承、转换、获得额外属性，必须分别规定读取基础值还是最终值，以及目标侧还能应用哪些增幅。

简化示例：胸甲基础护盾100点，装备局部固定护盾50点，局部护盾提高100%，胸甲最终提供300点护盾。其他全局固定护盾50点，全局护盾提高100%，角色最大护盾为700点。再增加20%的同层级普通护盾增幅后，结果为770点，而不是840点。该例忽略品质、取整和特殊来源。

### 1.3 标签与事件

- 伤害类型：物理、闪电、冰霜、火焰、虚空。
- 元素标签：本稿默认包含闪电、冰霜、火焰；虚空按用户指定的真实伤害单独处理。
- 形态标签：范围、投射物、召唤物等；形态标签可以与伤害类型叠加。
- 行为标签：主动施放、触发、重复、引导等。
- 状态与事件分开：“处于低血”是状态，“进入低血”是事件。
- 命中、持续伤害跳动、消耗、牺牲、伤害造成的资源损失、资源保留分别结算。

```text

```

### 3.10 关键规则

- 提前开始回充改变等待时间，提高回充速度改变启动后的恢复速率。
- 回充、再生、偷取、瞬间获得护盾是独立入口。“不能回充”不应自动禁止其他入口。
- 持续恢复效率的默认适用范围是随时间发生的恢复；瞬间获得护盾是否受益，需要另行明示。
- 偷取比例决定产生多少偷取量，每秒偷取上限决定实际恢复瓶颈。
- 满盾保留偷取效果，不等于允许恢复超过最大护盾。
- 自然回充、主动消耗、牺牲和被敌人击破分开处理。
- 溢出护盾是当前值超过正常最大值，不自动提高最大护盾，也不自动提高按最大护盾计算的伤害。
- 溢出衰减仅在基础规则存在衰减时适用；允许溢出的恢复来源需要明确指定。

- 受到伤害、消耗气血、牺牲气血和保留气血是不同操作。

- 延迟损失改变扣除时间，伤害回收提供后续恢复，二者不应重复计算为同一份减伤。
- 濒死保留气血和致命伤害后恢复，需要在死亡判定前完成对应拦截规则。
- “受到的治疗效果”是否作用于再生、偷取、药剂和事件恢复，应统一定义。

- 被动闪避判定与主动闪避动作分别计事件，完成翻滚不等于成功闪避一次敌方攻击。
- 闪避成功后的下一击增益需要规定持续时间、叠层与刷新规则。
- 失败补偿可以改善连续受击体验，但应避免多来源累计绕过概率上限。

### 14.8 关键规则

- 死亡、牺牲、到期消失、被替换分别作为事件。
- 召唤物的命中、暴击、击杀默认属于召唤物，需要联动玩家时明确写出。
- 继承基础属性与继承最终属性分别配置，避免玩家与召唤物增幅重复放大同一来源。
- 召唤物伤害默认读取召唤物自己的技能与属性；玩家普通伤害词缀不自动作用于召唤物。
- 召唤物之间的增益需要决定是否包含自身、临时召唤物和衍生召唤物。
- 双向承担伤害需要标记转移来源，避免转移的伤害再次相互转移。
- 临时召唤、复活和死亡爆炸相互触发时，需要冷却、数量和衍生代数限制。
- 永久召唤物与临时召唤物分别配置持续时间、复活、替换和精神占用。

### 15.8 关键规则

- 一次施放命中十个敌人，通常产生一次施放事件和十次命中事件；是否最多触发一次应另设限制。
- 单技能冷却、触发器共享冷却、同目标触发间隔分别配置。
- 默认触发技能不能再次触发其他技能；特殊连锁设置最大代数与每帧执行预算。
- 概率触发与累计触发分别配置，累计量在冷却中是否积累、失败后是否扣除都要明确。
- 概率检定失败、技能冷却、无目标、资源不足分别记录；“触发失败补偿”默认只处理概率检定失败。
- 冷却恢复速度提高与直接缩短冷却时间不等价。例如冷却恢复速度提高100%，通常对应冷却时间减半。
- 触发支付消耗、消耗返还、储存次数扣除和冷却启动需使用明确顺序。
- “处于低血时”需搭配周期或另一事件；“进入低血时”只在跨越阈值时发生。
- 无目标时是否取消、对尸体位置释放或改为自身位置释放，需要按技能指定。
- “触发技能效果”应绑定具体可缩放参数，不默认同时放大伤害、控制时长和召唤数量。

## 17 跨体系规则与配置检查

### 17.1 必须统一的结算规则

1. 基础值、装备局部值、全局增幅、独立倍率分别处在哪个阶段。
2. 增加概率与提高概率如何叠加，概率、抗性、控制效果和减伤的上限是多少。
3. 命中伤害、持续伤害、反击、反射、触发、终结分别使用哪些标签。
4. 元素是否仅包含闪电、冰霜、火焰；虚空真实伤害能否受通用减伤和承伤增幅影响。
5. 伤害是否先进行命中与格挡判定，再分配护盾、气血及其他资源。
6. 攻击、法术、投射物、范围、召唤物等标签可以叠加，但同一条普通增伤不因多个匹配标签重复计入。
7. 转换和获得额外伤害以哪一阶段为来源，来源与目标增幅如何避免重复应用。
8. 资源消耗、牺牲、伤害损失、延迟损失、保留与恢复分别产生哪些事件。
9. 直接命中、异常状态、召唤物和触发技能的击败归属如何传递。
10. 目标进入低血、回满、层数达到阈值，是跨阈值事件还是持续满足条件。
11. 词条读取施放时快照还是每次结算时的当前属性。
12. 重复、衍生、传播和触发链的最大代数、单目标间隔与场上数量如何限制。

### 17.2 不应混用的概念

| 概念一 | 概念二 | 区别 |
| --- | --- | --- |
| 普通增幅 | 独立倍率 | 前者同层级加算，后者单独乘算 |
| 获得额外伤害 | 伤害转换 | 前者保留来源并新增伤害，后者转走来源 |
| 气血恢复 | 气血再生 | 恢复是总类，再生是特定入口 |
| 护盾回充 | 护盾再生 | 启动条件与适用增幅分别定义 |
| 偷取比例 | 偷取上限 | 产生的量与每秒可恢复的量不同 |
| 最大护盾 | 溢出护盾 | 上限与当前超额资源不同 |
| 闪避值 | 闪避概率 | 公式输入与最终判定不同 |
| 主动闪避动作 | 被动闪避成功 | 动作事件与防御判定不同 |
| 格挡概率 | 格挡减伤 | 触发概率与成功后的承伤比例不同 |
| 范围面积 | 范围半径 | 对覆盖面积的缩放不同 |
| 施放距离 | 伤害范围 | 放置地点与覆盖区域不同 |
| 持续伤害频率 | 持续伤害结算速度 | 可分别改变跳动间隔与打完总伤害的时间 |
| 毒的伤害来源 | 毒自身伤害类型 | 来源为虚空不自动使毒成为真实伤害 |
| 点燃 | 燃烧地面 | 不同来源，不自动互相施加 |
| 真实伤害 | 绕过护盾 | 伤害减免规则与承伤资源分配不同 |
| 同批多投射物 | 单个投射物重复命中 | 数量规则与重复碰撞规则不同 |
| 召唤物死亡 | 召唤物到期消失 | 可触发不同效果 |
| 触发 | 重复 | 重新满足事件条件与一次执行内重复不同 |
| 冷却恢复速度 | 冷却时间减少 | 缩放公式不同 |

| 读取阶段 | 施放快照、命中快照、实时读取 |
| 计数范围 | 每次施放、每个投射物、每目标、每个召唤物、角色全局 |
| 冷却与次数 | 独立冷却、共享冷却、同目标间隔、储存次数 |
| 增益规则 | 是否叠层、最大层数、持续时间、刷新或覆盖 |
| 消耗规则 | 消耗什么资源、何时扣除、失败是否返还 |
| 目标选择 | 自身、事件目标、位置、标记目标、随机或优先级 |
| 继承规则 | 来源属性、继承比例、衍生对象可继承的能力 |
| 互斥关系 | 不能并存或需要覆盖的形态与机制 |
| 限制 | 概率、伤害、层数、目标数、场上数量、衍生代数上限 |
| 掉落与成长 | 稀有度、档位、权重、等级要求和获取来源 |

### 17.4 本轮汇总的统一调整

- 补齐火焰普通增伤，并把原始额外伤害表述拆为独立倍率与获得额外伤害。
- 将虚空从元素标签中独立出来，按真实伤害设计，不保留虚空抗性穿透。
- 中毒降低虚空抗性调整为提高目标受到的虚空伤害，作为需要明确是否生效的承伤增幅。
- 把原先未注明的“技能范围”统一为“技能范围面积”；需要半径成长时单独写半径。
- 直接增加概率或比例的词条使用百分点，相对增幅继续使用百分比。
- 额外提高统一表示独立倍率；所有占位符保持待配置，不预设最终数值。

各章节有意保留适用于不同体系的相似词条，例如格挡回盾、投射物命中回血、召唤物命中回盾。这些是同一底层能力在不同标签和事件条件下的具体组合，不代表应在数值结算时重复应用。
