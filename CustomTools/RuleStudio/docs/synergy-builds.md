# 多词条联动体验 BD

2026-10-25。入口：本地网站 → 3D 战斗 → 左侧「可用 BD」。三套均可一键应用；每套五件稀有 T10 装备，每件六条品质词条，没有套装加成。装备为按十阶区间创建的体验样品，不表示实际爬塔掉落所得。

## 霜雷交响

手动持续施放冰锥术。多重、向目标汇聚、穿透增加有效命中；「冰缓冻结」与冰缓效果提供冻结。「移除冻结」消费已有冻结并强化命中，触发挂载的雷霆新星。感电概率、额外感电层与「消耗全部感电」继续强化雷伤并提供异常消费事件。范围重复放大新星覆盖，范围命中回蓝、触发减耗与命中回血维持续航。

```text
冰锥命中 → 冰缓 / 冻结 → 后续命中消费冻结 → 雷霆新星
                    ↑                         ↓
              继续施放冰锥          消费感电强化雷伤，再施加感电
```

关键点：冻结必须先存在，再被下一次命中消费；不是看到冰缓就一定触发。没有敌人就没有新命中或异常消费。触发有冷却与真实魔力成本，说明不承诺空场永久施法。

核心词条：`freezing_hits`、`freeze_consume`、`consume_lightning_nova`、`shock_consume`、`shock_chance`、`shock_extra_layers`、`proj_count`、`proj_pierce`、`proj_layout_converge`、`area_repeats`。

## 瘟疫回潮

朝怪群投毒瓶约三秒，再松开施法。多枚瓶体与破裂范围制造施毒机会；每次额外毒层、对已中毒目标额外毒层使目标达到五层门槛，消耗全部中毒引爆。新增复合词条在消费中毒后触发一轮完整毒瓶技能，包含破裂和施毒两个辅助特性。

```text
毒瓶破裂 → 叠毒 → 达到五层 → 消费中毒并引爆 → 在消费位置续投毒瓶
                         ↑                         ↓
                         └──── 重复投瓶再次叠毒 ────┘
```

「在触发事件位置释放」让下一轮从怪群中产生；「触发技能额外重复」把后续瓶体铺到触发冷却恢复之后。缺少重复时，同一批毒层可能在触发次数尚未恢复时被全部消费，链路就会停止。两件装备各提供一条 T10 触发减耗，合计将触发消耗降至零，代价是占用两条随机词条；没有额外注入魔力。引爆结算剩余毒伤，因此中毒持续时间也提高爆发额度；引爆伤害、结算比例与范围分别放大结果。击杀传播与毒池负责转场覆盖，中毒敌人伤害降低提供额外防御。

关键点：需要活目标继续叠毒；清空怪群、目标离开覆盖或链路失配时，重新手动投瓶。没有用无条件计时器托底。五层门槛使用合法 T1 数值，其余主要词条为 T10；低阶门槛是构筑选择，不在战斗时按阶级换算。

核心词条：`poison_threshold_detonate`、`poison_extra_layers`、`poison_extra_on_poisoned`、`consume_poison_flask`、`trigger_at_event`、`trigger_repeat`、`trigger_cooldown_recovery`、`poison_duration`、`poison_detonate_ratio`。

触发投瓶的起点与落点分别处理：「在事件位置释放」决定从哪里生成；通用触发施法路径再把选中的敌人坐标传给抛物线规则。无活目标时，优先保留目标事件的位置快照，其次使用当前鼠标瞄准点。落点在发射时固定。同点生成时原地起落或立即接触敌人，不再因漏传落点而按 T10 的速度 24 × 寿命 1.1 向外飞行 26.4 米。直线投射物不读取这个落点字段。

## 献祭雷铸

装备上的「获得主动技能：献祭」词条授予技能，应用 BD 后自动装配到第 2 槽；卸下装备或洗掉该词条会失去技能。先用第 1 槽召唤铁刃守卫，等铁卫接敌，再按 **2** 切换献祭，用左键 / 空格施放。献祭消耗最早的一只存活控制单位，立即恢复最大气血的一部分，并将该铁卫的剩余气血转成护盾。复合触发词条在献祭位置先释放雷霆新星，随后补召铁卫。持续施放献祭可继续循环，使用普通技能的施法速度、魔力消耗与 1 秒基础冷却；不再有额外 V 快捷键。需要两个挂载名额，因此配有「可挂载的触发技能数量 +1」。控制单位上限和同类数量上限各增加一，场上最多两只铁卫。

```text
铁卫接敌 → 第2槽施放献祭 → 气血 / 护盾回复
                      ↓
           献祭位置雷霆新星 → 补召铁卫 → 下一次献祭施法
```

召唤物气血提高可转化的护盾量；护盾溢出允许恢复超过上限，并在溢出存在时提供增伤。护盾上限、气血转护盾及护盾附加闪电把防御投入用于新星输出。范围重复、触发增伤和闪电穿透补充攻击维度。

关键点：剩余气血越低，转化护盾越少；没有召唤物时施法不产生献祭事件或献祭回复，仍按普通施法支付资源与进入冷却。持续施法的节奏受主动技能冷却、触发冷却和魔力约束；自然到期、替换或被击杀都不等于主动献祭。召唤与献祭是独立技能，授予词条本身没有 cast 规则，不会把献祭混入每次普通施法。没有按 BD 名字分支的自动补召逻辑。

核心词条：`grant_sacrifice`、`sacrifice_thunder_guard`、`trigger_mount`、`trigger_at_event`、`trigger_order_sequence`、`control_unit_cap`、`minion_cap_same`、`minion_life`、`minion_sacrifice_life`、`minion_sacrifice_shield`、`shield_overflow`、`shield_overflow_damage`。献祭装备修订为 v2，替换一条召唤物攻速词条以容纳技能授予，仍是五件稀有装备、每件六词条。

## 新增内容与实现归属

- 新主动特性 `Traits/create_lightning_nova.json`：普通 `cast → damage_area`，参数为半径、基础点伤、手动冷却。
- 技能集合 `Builds/lightning_nova.json`：创建雷霆新星 + 既有感电，遵循主动与辅助特性聚合。
- 普通武器 `Equipment/thunderheart_scepter.json`：鸣核权杖，只绑定雷霆新星，可正常掉落；传奇品质使用既有闪电乘区词条。图标复用现有闪电技能美术。
- 传奇戒指 `Equipment/rime_thunder_annihilation_ring.json`：霜雷·鸣灭指环，固定「消耗目标异常状态时，有100%概率触发雷霆新星」，其余五条词缀正常随机。既有 `trig_ailment_consumed` 事件挂载完整新星（创建雷霆新星 + 感电），不增加战斗逻辑。专用传奇特性的 `chance` 在 `Values/trait_tiers.json` 十阶均为 100；新星载荷仍按正常 T 阶生成，洗炼保留固定词条。普通概率词条保持原样；新戒指可通过 GM 商店（0价）、传奇掉落与层间商人获得，不自动替换已持有装备或 BD 样品。
- 三条新复合词条由 `engine/trigger-skill-affixes.mjs` 声明：消费异常触发新星、消费异常触发毒瓶、献祭触发新星与铁卫。进入普通词条池，使用原有触发器与完整技能缝合，不新增战斗动作或私有计时器。
- `scripts/create-synergy-bds.mjs` 只生成装备数值与预设目录；战斗不读取 BD ID，也不按名字分支。
- 旧版万剑、余烬的种子样品使用 `scripts/reference-affix-pool.json` 保存制作时的目录；后续新增词条不会重新洗掉其已发布随机属性。正常游戏的掉落和洗炼仍取实时词条池。

## 验证

`node --test tests/synergy-bds.test.mjs` 覆盖词条洗炼和十阶、应用存档保留、真实冻结/感电消费、毒瓶松手续投、献祭回复与补召、拔除关键词条后的断链、空场与密集目标队列上限。使用正常角色资源，未开启无敌；训练目标只用于隔离验证机制，不代表爬塔层数结论。

`node scripts/create-synergy-bds.mjs` 可重建三套体验样品。所有当前测试由 `npm test` 执行。当前交付范围为网站；没有将未运行的 UE 实机验证标为通过。
