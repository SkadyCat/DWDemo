# 异常地面、镜像与旋风染色

2026-10-25，Opus Studio 5291。入口：<http://127.0.0.1:5291/?bd=whirlwind_grounds>，应用「旋风·四色染地」。

## 可洗词条

| ID | 名称 | 地面效果 | 旋风颜色 |
| --- | --- | --- | --- |
| `hit_burning_ground` | 命中时，有n%概率生成燃烧地面 | 每0.5秒结算火焰持续伤害 | 橙 |
| `hit_chilled_ground` | 命中时，有n%概率生成冰缓地面 | 每0.5秒施加0.75秒冰缓 | 冰蓝 |
| `hit_shocked_ground` | 命中时，有n%概率生成感电地面 | 每0.5秒施加0.75秒感电 | 紫 |
| `hit_poison_ground` | 命中时，有n%概率生成毒性地面 | 每0.5秒施加一层基础持续2秒的中毒 | 绿 |
| `hit_mirror_ground` | 命中时，有n%概率生成镜像地面 | 每次进入复制一枚真实投射物 | 银白反光地面，不改投射物颜色 |
| `proj_ground_contact` | 接触地面 | 独立机制，按扫掠、半径、高度记录进入和退出 | 无独立颜色 |
| `proj_ground_tint` | 投射物接触异常地面时染色 | 独立机制，不包含额外伤害、元素转化或异常附着 | 根据实际接触 |

五种地面都是命中触发的角色词条，使用现有 `sheet.trigger` 装配和运行时规则扩展方式；手动与触发技能的有效命中均可生成，持续伤害、召唤物命中和静默附加伤害不触发。规则 ID 与 BD ID 无关。移除装备上的来源后停止新生成，已生成地面按原寿命结束。

默认 `chance=25`（百分比）、`radius=2`（米）、`duration=4`（秒）、`cooldown=1`（秒）。`amount` 分别为每秒火伤12、冰缓强度30、感电强度20、每层基础每秒毒伤12。中毒继续受到已有中毒增伤、层数和结算速度等规则影响；冰缓、感电走原状态施加与上限。所有数值沿用上层 T1–T10 分配，接触、染色机制没有数值阶级。

同一词条共用冷却，多目标命中不能绕过；重复生成独立地面，不刷新旧地面的时长。新触发地面共用128块上限，超出替换最早的一块；硬限制为半径20米、寿命60秒、冷却至少0.05秒。地面每0.5秒结算，不产生命中事件，不能靠自身持续伤害递归生成。旧地面的原有规则与数量政策保留。

用途分类与前后缀仍是上层表：燃烧、毒性为攻击型前缀，冰缓、感电、镜像为特殊型前缀，接触和染色为特殊型后缀。装备掉落和洗炼沿用现有部位约束。

## 接触规则

旋风现在由「创建旋风 + 投射物随机游走 + 接触地面 + 地面染色」聚合。染色开关是一条独立特性，可供其他投射物组合；目前旋风预制体消费颜色数据。

接触读取真实载体的上一帧至当前位置、碰撞半径、高度与真实地面圆域，支持高速穿过小片地面；高于地面的投射物不会因水平投影重合就染色。颜色留到投射物消失，进入另一块地面时覆盖。重叠地面按本次移动最后进入的那块决定，同一接触时刻按稳定地面ID确定；留在交叠区不逐帧抢色。新载体默认无色，不共享前一枚的染色状态。

除新增五种地面，还读取原有燃烧地面、毒池、冻结结束的冰缓区域、投射物留下的元素区域、范围技能结束后的圆形地面。普通瞬时爆炸和非地面的持续技能不参与。

染色保存于单个投射物的运行时状态 `groundTint`；不会写载体的 `element`、伤害、tag、轨迹或寿命。表现层只读该状态，通过原旋风材质的颜色 uniform 与碎屑颜色显示，不重建网格或材质、不增加旋风绘制次数、不消耗战斗随机数。五种地面分别批量绘制；共用的独立地面绘制模块避免复制五套着色器，普通透明混合防止重叠过曝。

地面表现使用泼洒液斑：不规则的液体团块和细长溅痕、分离液珠，没有完整圆环边缘。每块真实地面在表现适配器中获得独立且稳定的种子、朝向和流动速度；首次出现约半秒内摊开、甩出液滴，之后偶尔溅起小滴。每块地面的8张液滴卡片与液斑合并在同一实例几何体内，弹道在GPU上按各自方向、速度与高度播放，每种地面仍只需一次实例绘制。批次排序改变、旧地面消失时，存活地面的种子与年龄保持不变；随机外观不调用战斗随机数。实际伤害与染色接触仍使用原地面圆域。

## 体验与验证

「旋风·四色染地」使用风暴群的数量链路，在武器、手套、头盔、副手各换入一种地面词条。仍是九件装备、44条随机词条；没有增加额外槽位或突破部位池。新预设与原「风暴群」分开，保留原构筑。已移除定时触发旋风，使用手动施放、镜像进出复制与回响；镜像复制体具有正常施法的独立命中预算。

`tests/ground-fields.test.mjs` 验证真实命中生成、四类伤害/状态、概率与冷却、无目标零生成、高速扫掠和高度、重叠覆盖与离开保色、旧地面接入、寿命/容量、视觉开关前后伤害与随机一致、真实四类染色预设。现有旋风、词条分类、十阶和特效测试同步运行。
