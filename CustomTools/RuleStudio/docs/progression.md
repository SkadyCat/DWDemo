# 角色成长、主线任务与新手引导

日期：2026 年 10 月 31 日。范围：RuleStudio 3D 战斗（`/?view=battle`，纯游戏模式加 `&play=1`）。

规则引擎（`engine/`）没有改动。新增玩法都在上层 `public/progression/`，数值调整只改 `Content/Rules` 下的数据文件。

## 试玩

- macOS：双击仓库根目录的 `Start-Game.command`。
- 命令行：`node CustomTools/RuleStudio/server.mjs`，然后打开 `http://127.0.0.1:5291/?view=battle&play=1`。
- 未运行 `npm run setup`（没有 esbuild）时，服务会自动改用源码模式。
- 纯游戏模式隐藏编辑器侧栏，以及「特质装备」「可用 BD」「商店」三个开发入口。
- `?debug=1` 会在 `window.__dw` 暴露战斗与存档句柄，只用于自动化试玩。

## 角色等级

- 等级 1–60。升级所需经验为 `30·L^1.9 + 20·L`。
- 击杀经验按怪物稀有度给：普通 6、魔法 15、稀有 40、守卫 200，再乘以 `1.24^(层-1)`。
- 2.6 秒内连续击杀算连杀，每多一杀经验 +1%，最高 +50%。
- 升级会回满气血与魔力，并弹出横幅、特效和音效。
- 等级加成写成普通词条，放在一个 `kind: 'level'` 的被动部件里，和天赋部件一起进入 `loadout.passives`，由现有聚合计算。每级提供：基础气血 +12、气血上限 +1%、魔力 +3、物理/元素/虚空伤害各 +5%。
- 天生属性换算（任何等级都生效，使星盘上的属性点单独点亮也有效果）：
  - 每点力量 +2 气血
  - 每点体质 +3 气血
  - 每点敏捷 +6 闪避
  - 每点智力 +2 护盾
- 天赋点在战斗中为 `(等级-1)×2 + 任务奖励`，上限 120。原来自由设定的规划点数，在战斗内改为只读。旧存档的方案超出预算时整体返还，并给出提示。

## 首通奖励

每层第一次通关时：

- 额外获得 `80·1.24^(层-1)` 经验；
- 获得下一层的普通地图一张，保证世界地图不会因为缺少地图票而卡住。

| 章节 | 任务 |

| 一 · 初入高塔 | 初次交锋、第一层守卫（沿用原三选一武器）、武装自己、星盘初启（三选一光环指环） |

- 三选一奖励在任务完成时生成一次并保存在存档里，重新加载也不会重抽。
- 所有奖励都在发放前一次性生成，生成失败时存档保持不变。

## 新手引导

八个步骤依次为：移动 → 施法 → 击杀 → 拾取 → 守卫 → 领取武器 → 换装 → 世界地图。

- 每一步以玩家真实完成的行为为准；已经满足的步骤会静默跳过。
- 情境提示：未分配的天赋点、低血时提醒吃药、可领取的任务、首次获得灵石时提示洗炼。
- 引导可以随时跳过。

## 平衡探针

```sh
node scripts/balance-sim.mjs 1,3,5,8,10 1,10,20,35 starter,magic,rare
```

- 脚本使用真实的 `DungeonBattle`，并复用 `TowerPilot` 机器人，按「层数 × 等级 × 装备」网格输出通关用时。
- 机器人不会闪避，也不会喝药，结果可以看作偏保守的下限。
- 已知问题：第 11 层起的六种异界谱系（T10）单只数秒即可击杀 T10 稀有装备的角色，需要另行调整。

## 六域星盘（天赋）

替换原来的 1000 节点自由属性盘。原盘有 899 个节点完全相同（任选属性 +5），点天赋几乎没有取舍。

- **结构：** 中心是「启明」，外面一圈是 24 个节点的根基环（气血、魔力、护盾）。启明连出 6 个门，每个门通往一个领域。
- **领域：** 每个领域 45 个节点：
  - 4 个主干小节点；
  - 一个入口轮盘（6 个小节点环绕 1 个核心）；
  - 左右两条分支，各经过一个轮盘，终点是基石；
  - 中路一个防御向核心。
- **桥：** 相邻领域的分支之间有一座桥（7 个节点），可以横向串联两个领域，不必退回中心。
- **基石是终点：** 自动寻路不会穿过基石。

### 节奏

- 满级约有 120 点，约占全盘的三分之一，所以一个角色只能深入一到两个领域，再加一座桥。
- 门 → 主干 → 入口核心约 8 点（2–5 级）；第一个基石约 17 点（9–10 级）。

### 六域与基石

| 领域 | 主题 | 基石（收益 / 代价） |
| --- | --- | --- |
| 寒霜 | 冰缓、冻结、碎冰 | 永冬之心：冻结更快更久 / 火焰与闪电伤害额外降低 30% · 冰魄碎裂：对冻结敌人大幅暴击 / 冰缓持续时间 -40% |
| 雷霆 | 感电、连锁、施法速度 | 过载：感电层数与每层增伤 / 30% 消耗由气血支付 · 雷暴连锁：连锁 +2 且可回弹 / 闪电伤害额外降低 15% |
| 烈焰 | 点燃、燃烧爆炸 | 燎原：点燃叠层、蔓延、爆炸 / 最大气血 -10% · 以血为薪：按气血附加火焰伤害 / 技能全部改为消耗气血 |
| 蚀毒 | 中毒、侵蚀、虚空 | 瘟疫之主：多叠一层、上限 +10 / 中毒持续时间 -30% · 虚无吞噬：虚空额外伤害、侵蚀增伤 / 闪避额外降低 30% |
| 铁血 | 气血、护甲、格挡、低血 | 不灭之躯：气血额外 +25%、再生 / 无护盾、闪避减半 · 狂战：低血增伤与攻速 / 药剂恢复减半 |
| 灵契 | 召唤物 | 统御：召唤上限 +1 / 自身伤害额外降低 15% · 血契：召唤物替你承伤并回血 / 最大气血 -10% |

六座桥依次为：弹幕（投射物数量 +1）、元素调和、法域（范围）、嗜血（偷取）、迅影（闪避）、灵能护盾。

### 修改设计

- 所有数值都在 `scripts/create-talent-tree.mjs` 顶部的 `DOMAINS`、`BRIDGES`、`RING` 表里，改完重新运行脚本即可。
- 脚本会校验词条参数、连线交叉和节点间距。
- 负数参数表示代价，界面会显示为红色的「降低」。
