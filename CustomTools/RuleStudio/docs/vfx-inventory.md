# 技能网站特效需求统计

统计日期：2026-10-23。对象：`http://127.0.0.1:5290/` 的 RuleStudio 技能网站，重点是 Three.js「3D 战斗」页。已核对在线 `/api/rules`，规则根目录为 `G:/DungeonWorldBeta/Content/Rules`。

这是一份表现需求清单；预制体数量是下列拆分建议，规则库数量是当前网站实际返回的数据。

## 技能对应关系

| 技能 | 需要的主要表现 |
| --- | --- |
| 冰锥术 | 冰锥、冰霜命中、冰缓 / 冻结 / 感电 / 中毒、落雷；元素附加与转换按实际命中元素展示 |
| 烈焰爆发 | 火焰爆炸、圆 / 环 / 扇形区域、火焰命中与点燃；燃烧地面依词缀触发 |
| 裂地波 | 直线地裂、物理命中、沿线推进 / 重复 / 扩散 |
| 斩击 | 挥砍弧光、实际区域形状、物理命中 |
| 毒瓶 | 抛物线瓶体、破裂、毒雾、中毒；毒池依词缀触发 |
| 召唤哨卫 | 哨卫本体、冰锥、直落雷击、火焰新星；攻击样式由实际装备词条 / 特性决定 |
| 召唤灵仆 | 独立灵体、追击运动、利爪、出现 / 消失；召唤物爆炸复用元素爆炸 |
| 怪物飞弹 / 首领新星 | 虚空飞弹及环形发射组合；命中后效果按实际规则触发 |
| 爪击 / 怪物近战 | 爪痕 / 重击、物理命中与实际伤害范围 |

多重、穿透、分裂、折返、弹射、盘旋复用投射物预制体，跟随真实投射物的位置、数量和寿命；不各建一套伤害效果。九种怪物复用上述预制体。当前规则库没有独立的火球技能，火球外观可作为后续投射物风格预设，未计入本次必需数量。

## 表现层需要补齐的数据转接

1. `public/battle3d.mjs` 的范围渲染只使用扩散圆环，没有按 `shape` 绘制直线、环形和扇形。
2. `public/sim/battle.mjs` 的通用 `areas` 记录没有保留完整的 `effect / inner / width / angle`；纯表现适配需要这些字段来识别效果与真实边界。
3. 哨卫落雷走 `damage_target`，连锁电弧走非范围命中；它们不会进入当前只监听 `area + death_lightning` 的雷击表现路径。
4. `combat/zones.mjs`、`combat/projectiles.mjs`、`combat/ailments.mjs` 已有区域 `view()` 数据，3D 渲染尚未消费，导致持续区域只有结算，没有持续可见范围。
5. 召唤渲染需要按 `kind` 区分 `sentinel` 与 `spirit`，并依据实际位置、方向与存续时间更新。
6. 状态附着需同时支持玩家、怪物和可受状态影响的召唤物，显示状态存在、剩余时间和层数，避免仅改变整个人物的颜色。

预制体使用单文件或独立文件夹，接收 Three.js 与表现参数，提供创建、更新、销毁接口；预览与实战使用同一份预制体。规则 / 背包 / UI 状态通过外层适配传入。伤害、碰撞、目标、数量、范围、冷却、状态持续时间继续由现有运行数据决定。

首批优先顺序：冰锥与元素命中 / 爆炸 → 死亡闪电、哨卫落雷与连锁电弧 → 冰缓、感电、冻结等状态 → 范围形状与持续地面 → 召唤与近战表现。
