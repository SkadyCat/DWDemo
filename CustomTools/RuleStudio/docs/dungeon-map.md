# 地牢小地图

右上角是圆形视野，跟随玩家位置及朝向。滚轮和加减按钮调整到 100%–400%；点击圆形区域、展开按钮或右侧「地牢地图」打开本层地图。在战场上按 Tab 也可打开。M 继续打开世界地图。

展开界面支持拖动、滚轮、加减按钮、方向键平移，F 定位角色，0 或「全图」复位，Esc 返回。打开时保存原暂停状态并暂停战斗，关闭时恢复。入口、首领、玩家和已开启的出口读取当前地牢数据；不修改刷怪、探索和通关规则。

拖拽范围随当前缩放和地图内容变化，边缘保留32像素间距。内容能完整放入视口时保持居中；放大后允许在内容范围内平移。手指或鼠标越界时逐渐增加阻力，松手用260毫秒缓动返回最近边界。回弹中可重新抓取，失焦或取消拖动也会归位；关闭界面、换图、缩放和定位会取消旧动画。系统启用减少动态效果时直接归位。

UICreator 工程为 `opus-dungeon-map`，源文件在 `UIAuthoring/DungeonMap.uialpha.json`。`Tools/UI/Author-DungeonMap.mjs` 将独立控件工厂保存为可编辑的 UICreator 工程。布局、按钮、图例、圆形裁切和标记图形由 `UICreatorAlpha/src/assets/rulestudio-hud/dungeon-map.js` 定义，网页适配层只投影实时地图数据并处理视角交互。

静态地牢几何只在换图时创建。运行时只更新视角、房间颜色和几个标记，不增加游戏逻辑定时器。验证记录位于 `Saved/Verification/DungeonMap/`。
