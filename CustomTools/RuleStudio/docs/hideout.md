# 藏身处

入口：[Opus Studio 5291 藏身处](http://127.0.0.1:5291/?view=hideout)，侧栏位于「3D 战斗」正下方。

这是独立的 Three.js 场景。点击仓库或商家商品的标签/场景物件立即打开对应界面，不依赖玩家位置。场景移动仍可选；返回战斗沿用当前战斗实例，在藏身处时战斗页停止推进。

## 仓库

- 背包与仓库各显示六行十二格，支持拖放、分页、名称搜索、物品详情和数量选择；双击可转移整堆，也可用按钮转移指定数量。
- 物品详情复用战斗页的通用 hover 浮窗，移出关闭，Ctrl 固定；底部仅保留数量与转移操作。仓库和商品读取各自保存的完整实例，取回背包后可装备、鉴定或加工。
- 装备保留原实例 UID、T 阶、所有词条数值及洗炼选择。装备必须先卸下；固定装备和已掌握技能不进入仓库。
- 道具可部分或全部存取。全部存入时清理对应快捷栏；部分存入保留剩余数量和快捷栏配置。
- 仓库只保存所有权，不参加战斗聚合。数据放在现有玩家存档的 `hideout.stash`，刷新或切换页面保留；新建/重置角色时一同清空。

## 商家商品

左侧背包，右侧商家商品，各为六行十二格。将背包物品拖到右侧即上架，将商品拖回左侧即下架；也可选物品、指定数量后使用上架/下架按钮。支持在同一容器内移动、交换或合并物品堆。搜索时拖放按照物品归属转移，不将搜索结果序号当作实际格子位置。

上架转移真实物品的所有权，不复制装备或重抽词条，也不直接出售换钱。已装备的装备需先卸下，固定装备和技能不可上架；道具可按数量上架，全部离开背包后清理对应快捷栏。上架物品不参与战斗聚合。

商品保存在 `hideout.merchant.inventory`，随现有玩家存档保存 UID、T 阶、词条、数量与格子位置。旧版随机 NPC 货单会移除，既有仓库和已经买入的装备保留。层末流浪商人及原 GM 商店继续使用原有逻辑。

## 代码与验证

`public/hideout/` 内的 `scene.mjs` 只管场景、行走、碰撞和交互；`model.mjs` 只管仓库与交易；`page.mjs`、`style.css` 连接已有背包、窗口和图标。场景不依赖战斗规则世界。

地砖、重复墙体和木构件使用实例化合批。静止时按需重绘；打开界面阻止场景输入，离开页签停止动画帧。

首次进入在完整灯光配置后使用 `compileAsync` 并行预编译材质，编译结果随场景复用。画布只在实际尺寸变化时调整，避免重复清空和重新分配。相机矩阵在投影标签前更新；异步准备期间离开或快速切换页签，也不会启动过期的绘制循环。

`tests/hideout.test.mjs` 验证物品守恒、装备完整往返、堆叠与拆分位置、无效转移原子性、商品持久化、旧货单迁移、点击立即交互和场景资源。浏览器验证脚本、记录与截图位于 `G:/DungeonWorldOpus/Saved/Hideout/`，覆盖点击打开、真实拖放、上架/下架、仓库存取、刷新和窄窗口。
