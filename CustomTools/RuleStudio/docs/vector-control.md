# 光环与矢量操控（Opus 网页）

`vector_control` 是第一种光环技能，由非武器装备授予。第一件底材是戒指「逆矢指环」（`vector_control_ring`），商店装备页与普通装备掉落均可获得。装备戒指后，点击战斗右侧任意 Q/E/F/G 槽打开与1–4相同样式的就地配置弹窗，选择矢量操控或消耗品；可跨槽移入，也可清空。已占用槽点击仍是配置，右键也可打开配置；选择当前条目保留原配置与光环开关，不触发使用。按对应按键切换光环或使用消耗品，长按不重复切换。弹窗支持Esc、右上角关闭、点击外侧关闭，并与主动技能配置互斥。

光环初次装配关闭；位置与开关存档，跨层保留；卸下装备即移除效果与快捷栏绑定，单独持有旧技能也不会授予。光环不占用1–4，不产生施法事件或资源支付。

装备以现有 `skills` 字段绑定光环，生成实例时沿用 `skill` 绑定，洗炼随机词缀不会改变该绑定。逆矢指环的普通品质没有随机词缀，魔法1–2、稀有3–6、传奇5条随机加1条固定投射物速度词条，均沿用现有T阶与戒指部位词缀池。光环捕获数值仍由技能聚合提供，装备本体不会常驻捕获效果。

技能类型由主动特性的 `sheet` 标记声明：`aura_skill` 为光环、`trigger_skill` 为仅挂载触发技能，其余沿用主动技能。集合加载时推导类型元数据，用于商店与装配，不增加规则字段。武器不允许绑定光环，光环不再作为独立技能商品出售。上层装配只收集非武器装备实际授予且启用的光环，再普通聚合进玩家技能与防御源；标记与技能固有效果不进入随机装备词条池。

## 投射物捕获

矢量操控聚合 `vector_control` 类型标记与 `projectile_capture` 效果两个特性。效果依赖类型标记。基础捕获概率20%，在敌弹即将命中角色、原弹命中与结束逻辑执行前，以战斗种子判定。成功会安静移除原敌弹，创建玩家归属的真实投射物，原弹伤害、命中状态与结束爆炸均不结算。

回返的三次贝塞尔控制点从真实碰撞点出发，先沿来袭方向弯曲，再回到攻击来源位置。每步真实坐标参与规则世界的扫掠碰撞和地牢墙体检测。技能预制体只读取真实载体位置，不能提供独立假弹道或伤害。

捕获弹保留原弹种类、元素、基础速度、寿命、半径与点伤，聚合玩家装备、天赋、启用光环、当前持有特性的投射物修饰、增伤和附加点伤。使用正常投射物数量、发射位置、连续发射、穿透、连锁、分裂、返程和命中流程；贝塞尔弯曲阶段优先于普通追踪/游走路径，完成该段后继续普通路径规则。不会复制当前主动技能的发射动作，不追加手动施法或消耗回响。已经捕获的弹在关闭光环后正常完成，之后的新敌弹不再捕获。

捕获形状数值按0.001单位归一化以避免浮点朝向造成重复计划，查找缓存最多256项；载体沿用既有4096枚上限。概率、控制点偏移等数值在 Values 层有10阶，本次各阶保持指定基础值20%/2米。

## 触发－召唤扭曲之眼

`summon_twisted_eyes` 是可挂载触发技能，条件由现有触发特性提供。例：

```json
{"id":"trig_cast","params":{"chance":100},"with":["summon_twisted_eyes"]}
```

对应传奇项链「扭曲之瞳」（`twisted_eye_amulet`）已接入普通装备目录，GM商店装备页可免费购买，也可正常传奇掉落。固定传奇词条 `legendary_twisted_eye` 复用现有 `trig_cast` 触发机制，挂载完整 `summon_twisted_eyes` 技能：主动施法时按概率触发，每次创建1只、持续5秒；概率由上层十阶表生成，T1为60–64%，T10为97–100%，不增加战斗规则。旧项链通过现有固定传奇同步更新，保留随机词缀。其余五条随机词缀使用项链特殊型词缀池，洗炼保留固定触发。装备即生效，无须配置到主动或光环栏；项链与逆矢指环可同时装备。只有项链不会自动开启矢量操控，仍须装备戒指并通过Q/E/F/G启用光环。

动作 `spawn_monster` 创建10只 `twisted_eye`，5米环形分布，持续5秒，无敌。它们是普通敌方怪物实体，具备谱系、稀有度和塔地图属性三个固定装备槽，沿用怪物技能、索敌、攻击、碰撞与目标计数。基础飞弹虚空点伤10、速度12米/秒、寿命2秒、攻击冷却1秒，实际攻击继续经过怪物装备聚合。无敌覆盖直接命中、引擎状态持续伤害和网页地面/异常持续伤害。5秒到期直接移除，不产生击杀、掉落或死亡触发；已发射飞弹按各自寿命结束。

怪物定义停用自然生成、权重0；`monster_twisted_eye_bolt` 只供怪物使用。扭曲之眼的球体、虹膜与瞳孔使用实例化预制体，与伤害规则无关。

验证：`node --test tests/vector-control.test.mjs`，涵盖开关、所有权清理、真实曲线和命中、增幅继承、原弹逻辑抑制、种子概率、10只敌人、无敌和5秒无奖励到期。
