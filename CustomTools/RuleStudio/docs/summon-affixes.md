# 召唤物词条清单

状态：文档草案，供确认词条范围与文案。首批整理 **50 条独立数值词条**，全部对应现有特性，按伤害、数量、输出频率、攻击覆盖、生存与恢复分类。

依据当前网页版的 `Content/Rules/Affixes/`、`engine/combat/minions.mjs`、`projectiles.mjs`、`ailments.mjs` 和十阶表整理。下表的数值是**当前特性模板的默认参数**，方便对照已有内容；装备实际数值按现有 T 阶生成。本文不配置新的数值区间、掉落权重或传奇机制。

## 1. 数量与召唤维持（8 条）

| 词条文案 | 当前默认值 | 现有特性 ID | 作用 |
| --- | --- | --- | --- |
| 控制单位上限 +n个 | +1个 | `control_unit_cap` | 增加所有玩家召唤物共用的控制名额，默认总名额为 1 |
| 同类召唤物数量上限 +n个 | +1个 | `minion_cap_same` | 增加正常召唤时，同一种召唤物允许保留的数量 |
| 每次召唤数量 +n个 | +1个 | `minion_per_cast` | 召唤成功时，额外创建同类单位 |
| 召唤物持续时间 +n% | +30% | `minion_duration` | 延长召唤物存在时间 |
| 召唤物精神占用 -n% | -20% | `minion_spirit` | 降低单个正常召唤物占用的精神 |
| 召唤技能施放速度 +n% | +20% | `minion_summon_speed` | 加快玩家施放召唤技能 |
| 召唤技能冷却恢复速度 +n% | +30% | `minion_cooldown` | 加快玩家召唤技能的冷却恢复 |
| 召唤技能消耗 -n% | -25% | `minion_cost` | 降低玩家使用召唤技能的资源消耗 |

数量必须分清三个作用：**总共能控制几只、同类正常召唤能保留几只、一次额外生成几只**。每次召唤数量不增加控制名额；共用上限已满时，新单位会替换最早的单位，并沿用被替换单位的攻击节奏。

正常召唤还检查同类上限和精神预算。精神预算为 100，每只默认占用 20；精神占用降低不会自动增加控制上限。临时、强化、复活和额外副本都受共用控制上限约束，玩家本体与死亡闪电的雷暴效果不占名额。

现有 `minion_cap`（“召唤物数量上限 +n个”）与 `minion_cap_same` 都加在正常召唤的同类 cap 上，**不等于控制单位总上限**。首批清单选用含义明确的 `minion_cap_same`，避免把两条同效属性当成不同的数量维度。

## 2. 伤害（11 条）

| 词条文案 | 当前默认值 | 现有特性 ID | 作用 |
| --- | --- | --- | --- |
| 召唤物伤害 +n% | +30% | `minion_damage` | 提高召唤物命中伤害的普通增幅 |
| 召唤物伤害额外提高 n% | 额外提高20% | `minion_more` | 使用现有独立伤害乘区 |
| 召唤物基础物理伤害 +n点 | +6点 | `minion_flat_physical` | 增加召唤物物理命中的基础点伤 |
| 召唤物基础火焰伤害 +n点 | +6点 | `minion_flat_fire` | 增加召唤物火焰命中的基础点伤 |
| 召唤物基础冰霜伤害 +n点 | +6点 | `minion_flat_frost` | 增加召唤物冰霜命中的基础点伤 |
| 召唤物基础闪电伤害 +n点 | +6点 | `minion_flat_lightning` | 增加召唤物闪电命中的基础点伤 |
| 召唤物基础虚空伤害 +n点 | +6点 | `minion_flat_void` | 增加召唤物虚空命中的基础点伤 |
| 召唤物物理伤害 +n% | +30% | `minion_physical` | 提高物理命中伤害 |
| 召唤物元素伤害 +n% | +30% | `minion_elemental` | 当前作用于火焰、冰霜、闪电命中 |
| 召唤物虚空伤害 +n% | +30% | `minion_void` | 提高虚空命中伤害 |
| 召唤物持续伤害 +n% | +30% | `minion_dot` | 提高已有召唤物归属的持续伤害，需要先具备相应持续伤害来源 |

普通伤害增幅在同一增幅层累加，“额外提高”单独相乘。例如，仅考虑这两个召唤物词条，基础伤害 100、伤害 +30%、伤害额外提高 20%，结果为 `100 × 1.3 × 1.2 = 156`，之后仍按实际命中、暴击与防御结算。

**基础某类型伤害目前只加到该类型的命中上。** 例如，火球炮台的火球能获得基础火焰伤害；单独增加基础冰霜伤害，不会让火球自动额外打出一份冰霜伤害，也不会改变攻击内容。需要什么伤害来源，仍由既有攻击特性聚合提供。

## 3. 输出频率、暴击与命中（6 条）

| 词条文案 | 当前默认值 | 现有特性 ID | 作用 |
| --- | --- | --- | --- |
| 召唤物攻击速度 +n% | +20% | `minion_attack_speed` | 加快现有移动近战召唤物的攻击 |
| 召唤物施法速度 +n% | +20% | `minion_cast_speed` | 加快现有固定远程召唤物的攻击 |
| 召唤物技能冷却恢复速度 +n% | +20% | `minion_skill_cooldown` | 缩短召唤物自身的攻击间隔 |
| 召唤物暴击率 +n% | +50% | `minion_crit` | 对基础暴击率作相对增幅 |
| 召唤物暴击伤害 +n% | +30% | `minion_crit_multi` | 增加暴击伤害倍率的数值 |
| 召唤物命中率 +n% | +10% | `minion_accuracy` | 对召唤物基础命中率作相对增幅，最终不超过100% |

“玩家召唤技能的冷却”与“召唤物攻击间隔”分别由不同词条控制。铁刃守卫、赤焰战犬使用攻击速度；哨卫、火球炮台、引雷图腾使用施法速度；召唤物技能冷却恢复速度参与两者的攻击间隔计算。

召唤物基础暴击率为 5%，单独“暴击率 +50%”对应 7.5%，并非 55%。基础命中率为 90%，单独“命中率 +10%”对应 99%。暴击伤害 +30% 是向倍率加上30个百分点，例如倍率原为150%时变为180%。

## 4. 投射物、范围与接敌（7 条）

| 词条文案 | 当前默认值 | 现有特性 ID | 作用 |
| --- | --- | --- | --- |
| 召唤物投射物数量 +n个 | +1个 | `minion_proj_count` | 召唤物实际发射投射物时增加弹数 |
| 召唤物投射物飞行速度 +n% | +25% | `minion_proj_speed` | 加快实际投射物飞行 |
| 召唤物技能范围面积 +n% | +30% | `minion_area` | 扩大既有范围攻击的伤害面积 |
| 召唤物移动速度 +n% | +30% | `minion_move_speed` | 加快移动近战召唤物接敌与跟随 |
| 召唤物索敌距离 +n% | +30% | `minion_seek` | 扩大召唤物搜索敌人的距离 |
| 召唤物追击距离 +n% | +30% | `minion_chase` | 增加移动召唤物允许离开玩家追击的距离 |
| 召唤物攻击距离 +n% | +40% | `minion_attack_range` | 增加移动近战召唤物的出手距离 |

投射物数量作用于哨卫冰锥、炮台火球等实际弹体；引雷图腾的直接落雷不会因此变成多道投射物。移动速度、追击距离和近战攻击距离对固定炮台没有对应的移动收益。

召唤物的实际弹体同时接受**通用投射物词条与召唤物专属投射物词条**。例如，基础1枚、多重投射+4枚、通用投射物数量+2枚、召唤物投射物数量+1枚，最终每次发射8枚；通用弹速+25%与召唤物弹速+20%在同一百分比层相加，为基础弹速的1.45倍。主动召唤与命中触发召唤使用相同的聚合入口。

装备的穿透、弹射、连锁、分裂、追踪、环形、回归等既有投射物能力也作用于召唤物弹体，按各自原有条件结算。同批命中上限和伤害衰减按每次攻击重新计算，不能把召唤物整个存活期间都当成同一批；连续发射增加该次攻击的弹体批次，不重复创建召唤单位。多重自带的伤害倍率仍正常生效。

范围按**面积**计算：面积 +100%，半径约为原来的1.414倍。范围增幅不会把单体伤害自动改成范围伤害，索敌距离也不会自动延长投射物寿命；弹道能否到达目标仍取决于实际速度和存在时间。

| 召唤物气血上限 +n% | +30% | `minion_life` | 提高气血上限的普通增幅 |
| 召唤物气血上限额外提高 n% | 额外提高20% | `minion_life_more` | 使用现有独立气血乘区 |
| 召唤物基础护盾 +n点 | +40点 | `minion_shield_base` | 提供护盾基础数值 |
| 召唤物护盾上限 +n% | +30% | `minion_shield` | 放大已有的基础护盾或继承护盾 |
| 召唤物护甲 +n% | +50% | `minion_armour` | 提高护甲，减少物理命中伤害 |
| 召唤物闪避值 +n% | +50% | `minion_evasion` | 提高对攻击命中的闪避能力 |
| 召唤物攻击格挡率 +n个百分点 | +15个百分点 | `minion_block_attack` | 增加攻击格挡概率 |
| 召唤物法术格挡率 +n个百分点 | +15个百分点 | `minion_block_spell` | 增加法术格挡概率 |
| 召唤物元素抗性 +n个百分点 | +20个百分点 | `minion_resistance` | 增加火焰、冰霜、闪电抗性 |
| 召唤物受到的伤害 -n% | -15% | `minion_taken` | 降低受到的伤害 |
| 召唤物被召唤后的n秒内免疫伤害 | 1.5秒 | `minion_immune` | 提供召唤初期的保护时间 |

召唤物现有基础气血为150、基础护甲和闪避值各100。护盾没有凭空出现的基础值；只配置“护盾上限 +n%”，在基础护盾与继承护盾均为0时，结果仍然为0。

攻击和法术格挡概率分别受现有75%上限约束，格挡后承受该次伤害的30%。增加抗性、护甲、闪避或气血不会改变召唤物的攻击类型。

## 7. 数值与聚合约定

- 每行是一条独立词条；普通属性使用“对象 + 属性 + 数值与单位”的文案。条件恢复写明触发条件和恢复对象，不另起没有实际含义的名称。
- 有数值的词条沿用现有十阶结构；装备T阶限制可抽取的词条阶级，生成时保存实际参数。战斗规则读取普通参数，施法时不重新随机阶级。
- 数量是整数，不能为了凑出十个不同档位而生成小数单位。当前默认 +1个的上述数量属性，T1–T9为+1，T10为+2。
- 攻击内容由召唤特性与攻击特性聚合决定。伤害、数量、攻速等辅助词条改变已有能力，不单独创造火球、冰锥、持续伤害、感电或落雷攻击。
- 装备、技能、限时效果等来源继续通过现有聚合入口提供这些属性；不增加单独的召唤物伤害公式或装备专属战斗判断。

部分当前十阶区间示例，均读取 `Content/Rules/Values/trait_tiers.json`：

| 词条 | T1 | T10 |
| --- | --- | --- |
| 控制单位上限 | +1个 | +2个 |
| 召唤物伤害 | +15%～18% | +56%～60% |
| 召唤物伤害额外提高 | 10%～12% | 37%～40% |
| 召唤物基础物理伤害 | +3点 | +12点 |
| 召唤物基础气血 | +30～38点 | +111～120点 |

## 8. 首批之外的既有机制

满血增伤、同类数量联动、存活时间增伤、属性继承、死亡爆炸、牺牲、临时召唤和暴击触发辅助技能等已存在。这些需要单独核对触发条件与攻击来源，后续再整理；首批先明确上面的基础战斗属性。
