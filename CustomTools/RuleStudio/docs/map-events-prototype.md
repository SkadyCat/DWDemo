# Studio3D 地图奇遇原型

本轮先在 RuleStudio 的 3D 战斗页打磨原型，不导出或导入 UE。

入口：`/?view=battle&prototype=map-events`。该入口暂停战斗并打开合成祭坛；普通 3D 战斗页从右侧功能栏的“地图奇遇”祭坛图标打开，位于异界星图下方、设置上方。点击后在按钮左侧展开四个奇遇选择，顶部不再显示原型横条。再次点击、点击外部或按 Esc 收起选择；关闭祭坛返回右栏按钮。

## 合成祭坛

界面上方为两个独立装备投入格，下方为 8×3 装备背包。点击投入格选择左右侧，点击背包装备放入，也可将背包装备拖到投入格。

- 只能放入同部位、未穿戴、已鉴定的角色装备；同一实例不能重复使用。
- 上方仅保留两个投入格，下方为背包网格。悬停或键盘聚焦装备格查看完整词条，也可按 Ctrl 固定详情，Esc 关闭详情。固定传奇用金色标注。
- 先锁定两件，再次确认后消耗两件，生成一件新装备并直接放回背包。
- 结果保留左件的部位、底材、基础属性、技能和 T 阶。左右分别从 0 到全部词条中随机抽取，不放回，保留抽中词条的原始数值。固定传奇参与，允许多个传奇词条并存。
- 可以解除锁定；关闭界面保留本地图的投入选择与锁定状态。切换地图解除锁定，原装备保留。
- “补充两件原型测试装备”明确向当前浏览器存档加入两件传奇，便于试用；没有自动修改既有装备。

## 其他原型入口

百炼法坛使用现有通货加工事务，针对本地图绑定的一件装备免费重复加工。锁定前点击右侧通货格，在 `Content/MapEvents/events.json` 指定的下品灵石和陨星石之间切换；锁定后装备和通货固定。下品灵石可用“第 n 条 · 点击切换”按钮选择随机词条，首次制作后绑定该条，后续只洗炼这一条。陨星石重新生成整件装备的随机词条。实际通货数量、腰带和钱包不变，领取后法坛结束。

传奇三选一和宝库在本地图会话中只生成一次候选，领取一件后不能重复领取。当前使用右栏“地图奇遇”入口打开，地图随机分布和守卫挑战仍以后续玩法打磨为准。

## UICreator 来源

`scripts/author-map-events.mjs` 生成 `public/ui/map-events.uialpha.json`，并保存到 UICreator 项目 `opus-studio3d-map-events`。布局、装备格、按钮、品质皮肤均使用 UICreator 控件树与共享 SVG runtime；Vue 仅承载 SVG 和连接现有玩家状态。

`public/map-events-model.mjs` 处理合成及免费加工事务；`public/battle-map-events.mjs` 连接交互。

现有规则计算及普通装备生成数值不变。合成装备增加 `synthesized` 与 `extraLegendary` 字段，避免重载时恢复未抽中的原传奇，并让已有装备构筑聚合包含额外传奇。
