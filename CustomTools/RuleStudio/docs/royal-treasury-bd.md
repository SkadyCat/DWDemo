# 王之宝库 · 雷铸王权

## 天地乖离剑

王之宝库的三个预制 BD 将专属主动放在槽位2，槽位1继续收纳。既有宝库武器通过 `treasury_stock.sheet.grant_skill` 提供技能，不增加武器绑定数量；卸下宝库武器后移除装配资格。先用1启动并叠层，再切换2向点击位置释放。消耗自己的全部宝库层数，使用真实投射物从头顶6米处射向落点；基础32点物理伤害，本次技能伤害倍率为 `1 + 消耗层数 × 0.5`，10层6倍、40层21倍，装备附加点伤也按该倍率结算。投射物词条照常聚合，基础发射1枚。无层数不出剑，释放后需重新启动宝库。

层数读取与扣除使用已有 owner/channel/consume 规则。网页通用动作 `multiply_damage` 将消耗快照变为本次施法根的倍率，不影响旧兵器或其他技能；数值沿用十阶上层表，系数各阶固定0.5。`treasury_stock` 的收纳规则只在其作为主动时执行，终结技不会意外补回一层。表现使用独立 `ea.mjs`，只读取真实起点、方向、碰撞与时间；巨型赤金法阵快速展开，巨剑从阵面逐渐穿出，命中或落地时出现轰击效果。

Opus 5291 游戏内的可用 BD 列表新增「王之宝库·雷铸王权」，也可以打开 `/?bd=royal_treasury_sovereign` 后一键应用。配装是按当前获取规则生成的体验样品，并非玩家从零刷出的战绩。九件装备中两件传奇、六件稀有、一件魔法；所有随机词条服从部位池，数值保存在装备实例中。

| 提升方向 | 装备来源 | 实际结果 |
| --- | --- | --- |
| 减少叠满点击 | 天穹之钥的固定传奇词条 | T10 每次收纳10层，4次正常施放叠满；原技能1层/次的默认值不变 |
| 增加上限 | 同一固定传奇词条 | 上限40层；层数和闲置衰减仍由原有规则维护 |
| 增加投射物 | 武器固定基底+2、手套随机词条+2 | 每次随机出射共5枚；满层41次/秒的基础期望合计约205枚/秒，实际短时数量随机 |
| 附魔触发联动 | 闪电感电、基础/额外闪电、消费感电、鸣灭指环 | 兵器命中施加感电；后续闪电命中消费感电，触发雷霆新星，新星和兵器再次施加感电接续 |

使用主动技能槽1。施放间隔仍受原有0.65秒冷却约束；连续按住会逐次施放，四次即可叠满。满层后任意停手5秒减第一层，此后每2秒减一层；在5秒内补一次可保满。空场时异常消费和新星链停止，宝库继续按剩余层数发射。

核心数值采用已有集合参数覆盖：技能先提供 `treasury_stock`，传奇装备覆盖该特性的 amount/cap，聚合只保留同一规则的一份实现。`Values/trait_tiers.json` 为这条特性提供十阶上层数值；维持时间、衰减、出射系数和冷却在各阶保持默认值。普通王库之钥仍为1层/次、上限10层。移除核心武器即可恢复默认值，没有预设专用运行逻辑。

固定传奇词条与固定基底不会被普通洗炼移除；下方五条随机词条正常变化。手套多重、闪电附魔、消费感电以及触发减耗等都是实际随机词条，洗掉会相应削弱或切断联动。

追求顺序：核心收纳/上限 → 多重 → 附魔与消费感电 → 鸣灭指环 → 触发减耗/冷却恢复 → 同批命中上限、穿透 → 投射物乘区和闪电穿透。防具负责气血、护甲、抗性与回复。两条 T10 触发减耗相加超过100%，使触发消耗按现有规则归零；没有修改魔力或发放额外资源。

验证：`node scripts/research-royal-sovereign.mjs` 用真实 Battle、关闭无敌、固定靶8秒、四次输入测量。参考种子37的层数依次10/20/30/40，产生1550枚兵器；单靶约12.64万DPS，12靶总DPS约15.55万，平均单体约1.30万，最低魔力98。这是固定靶结果，不代表塔层通关结论。移除手套多重后每次5枚降为3枚；拆掉消费感电或附魔来源，新星触发数归零。

生成：`node scripts/create-royal-sovereign-bd.mjs`。回归：`node --test tests/royal-sovereign-bd.test.mjs`。

## 元素分支：万象熔炉

Opus 5291 的 `/?bd=royal_treasury_elements` 可一键应用。保留原雷铸王权，使用独立装备实例；九件T10装备为两件传奇、七件稀有。与雷铸王权共用天穹之钥和鸣灭指环底材，继续4次叠满40层、每次随机出射5枚、满层基础期望约205枚/秒。项链升级为六条特殊词缀的稀有样品，装备获取和洗炼仍受部位词条池限制。

| 实际联动 | 当前T10体验数值与作用 |
| --- | --- |
| 冰霜附魔、命中冰缓 → 中毒 | 冰缓目标被施加的中毒持续时间+77%；毒素引爆按剩余毒伤结算，因此同时放大毒爆 |
| 闪电附魔、感电 → 中毒 | 对感电目标施加的中毒伤害+77%；提高毒层强度，也提高其剩余伤害 |
| 火焰附魔、点燃 → 毒素引爆 | 对燃烧目标的引爆伤害+97%；引爆沿用每目标冷却，不会每枚兵器无限引爆 |
| 冰火雷命中 → 施毒 | 元素伤害计入中毒基础；高频命中概率施毒、额外毒层负责填充，引爆后重新积毒 |
| 中毒引爆或闪电消费感电 → 雷霆新星 | 鸣灭指环100%概率触发，仍受触发冷却/储存限制；项链额外重复2次，新星命中继续施毒、感电 |

这些是现有条件增益、状态消费和触发组合。没有新增通用元素配对表，没有额外的融化/蒸发规则；冰缓延毒不要求冻结，毒素引爆不消费冰缓或点燃。额外/衍生伤害沿用原有二次施加限制。

配装分工：武器放冰霜、火焰附魔与额外闪电；手套放多重、穿透、闪电感电、施毒；头盔放三条跨元素增益、额外毒层、投射命中回血，并以最大气血4%作为附加物理点伤；副手放毒爆比例/范围、感电层数/效果与触发增伤；戒指保留感电消费、触发资源与落点支持；项链承载元素计毒、命中引爆、冰缓概率和触发重复。胸甲、鞋、腰带继续提供气血、抗性、护甲与恢复。词缀是独立随机行，洗掉对应词缀就会损失对应路径。

优先顺序：收纳核心/多重 → 三元素附魔与施毒 → 命中引爆 → 冰缓延毒、感电增毒、燃烧增爆 → 鸣灭指环与减耗 → 额外毒层/引爆比例/范围/触发重复 → 气血点伤及防御。触发链需要敌人被实际命中；空场不会凭空增加异常或触发新星，宝库仍按自身层数和闲置规则运作。

真实Battle的参考种子37、12个静止高血量/20%抗性靶、8秒、4次输入：1550枚兵器、147次毒爆、132次新星，总秒伤约177987，平均单体约14832，最低魔力98，关闭无敌。拆掉冰缓延毒/感电增毒/燃烧增爆后，毒爆总伤害分别由约350687降至195703/210222/178014；拆掉施毒或命中引爆后毒爆归零，拆掉所有异常消费后新星归零。固定靶结果不等同于塔层通关或所有场景的DPS。

生成 `node scripts/create-royal-elements-bd.mjs`；测量 `node scripts/research-royal-elements.mjs`；回归 `node --test tests/royal-elements-bd.test.mjs`。两个进阶分支共用 `scripts/royal-treasury-equipment.mjs` 的上层装备构造与部位/阶级校验，战斗引擎不识别预设ID。
