# 索敌范围特性

怪物和召唤物通过普通特性面板配置基础索敌范围，单位为米，按水平距离计算。

| 特性 | 参数 | 使用者 |
| --- | --- | --- |
| `monster_seek_range` 怪物基础索敌范围 | `n`，默认 8 | 怪物自身特性、谱系装备、召唤者继承来源 |
| `minion_seek_range` 召唤物基础索敌范围 | `n`，默认 10 | 玩家当前召唤技能或装备提供的召唤物属性 |
| `minion_seek` 召唤物索敌距离 +% | 原有 `n` 百分比 | 在基础范围上继续计算 |

例如怪物配置 `{ "id": "monster_seek_range", "params": { "n": 4 } }` 后，4 米内才追击和发起新施法。范围变化会在下一次 AI 更新生效，其他怪物不受影响。技能本身的施放距离仍然单独生效。

召唤物基础范围为 4 米且索敌距离增加 50% 时，实际范围为 6 米。基础范围未配置时，继续使用该召唤技能原来的范围；已有召唤技能与百分比特性数值不变。

基础范围来自多个独立来源时相加。同一怪物特性列表仍按现有规则禁止重复 ID，可以通过怪物自身特性和装备分别提供。同类属性来源在编译时分配独立实例 ID，规则 VM 和属性组合方式不变。

基础范围小于等于 0 或召唤物范围倍率小于等于 0 时停止索敌，包括目标重叠的情况。移除召唤物基础范围特性后恢复技能默认；旧怪物数据未配置特性时兼容全局 DataAsset 默认值。现有 10 种怪物均显式配置原有的 8 米范围。

这两条基础范围特性不进入随机装备词条池。已有 `minion_seek` 百分比词条仍可正常生成。出生安全区、召唤物追击绳长、近战攻击距离和首领通关条件保持原规则。

Studio 与 UE 使用相同的 sheet 属性 `monster.seek_range`、`minion.seek_range`。UE 在原生 DWRules 和 AngelScript 中读取，没有 JavaScript 运行依赖。

验证：`node --test tests/seek-range.test.mjs`；原生自动化 `DWO.AI.SeekRangeTraits`；实际怪物验收 `-DWOTransient -DWOAggroTest`。
