游戏内 UI 样张（五版）

同一个角色、同一件传奇「永冬之心」、同一组特性，只换视觉方向。把鼠标移到装备或背包格子上，物品说明会跟过去；背包里的物品可以拖动。

  1. 圣铁暗金锻铁、鎏金浮雕、羊皮纸说明。厚重沉浸，最像传统 ARPG。
  2. 星轨玻璃磨砂玻璃、切角、发光细线、六边形血魔。现代商业感，信息密度高。
  3. 鎏金夜阙午夜蓝绸面、细金线、角花、圆形技能。华丽而克制。
  4. 墨卷宣纸面板、焦墨笔触、朱砂印章、毛笔数字。东方、反差最大。
  5. 像素奇幻（RPGUI）直接用 RPGUI 的像素木框与金框。复古、轻量。

图标：game-icons.net（CC BY 3.0）。动效 GSAP，说明框定位 Floating UI，拖拽 SortableJS，像素框 RPGUI。需要联网加载。
