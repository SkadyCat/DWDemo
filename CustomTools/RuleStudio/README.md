# RuleStudio · CustomTools 功能清单

异常消费反应：新增冰缓→小范围冰霜爆破、感电→中范围闪电击中、冻结→大范围破冰碎片三个独立被动特性，进入普通装备词缀池。沿用既有消费与范围伤害指令；范围、十阶数值及验证见 [异常消费特性](docs/ailment-reactions.md)。

Studio3D 加载加速：`npm run build:web` 生成版本化脚本与样式包，5291 自动使用；支持 Brotli/gzip、资源缓存、单次规则加载及按需加载 BD。COS 发布与配置见 [COS 加速](docs/cos-delivery.md)。

光环与魔力封印（Opus 5291）：新增火焰、冰霜、闪电、毒素、物理、虚空六种基础点伤光环，及闪避、护甲、护盾、四种单抗和全抗光环。每种分别绑定一枚指环和一件护符，共28个普通底材，进入GM商店与正常装备掉落；四种品质、T阶、固定基底及随机词条沿用现有生成。装备后在Q/E/F/G装配并切换，只有启用时聚合效果。所有光环（包括矢量操控）默认封印50%总魔力，各比例相加，超过100%不能开启；封印不是消耗/恢复，关闭不立即回蓝，回蓝与返还均不超过未封印上限。魔力条显示封印区域，角色面板显示总量、封印量及可用上限。生成 `node scripts/create-auras.mjs`；验证 `node --test tests/auras.test.mjs tests/aura-equipment.test.mjs tests/vector-control.test.mjs`。

藏身处（Opus 5291）：[进入场景](http://127.0.0.1:5291/?view=hideout)，侧栏在「3D 战斗」下方。点击仓库或商家商品立即打开双侧物品格；从背包拖入商品格上架，拖回下架。物品、词条与位置随玩家存档保存，切回战斗沿用当前进度。见 [藏身处说明](docs/hideout.md)。

任务系统（Opus 5291）：[进入游戏](http://127.0.0.1:5291/?view=battle)。新玩家默认装配冰锥术，左上角「初入高塔」引导通关第一层；击败守卫后从三把随机武器中选一把放入背包。任务、候选和领取状态随玩家存档保存，重复通关和刷新不重抽。点击任务卡、右侧任务图标或按 J 打开；说明与验证见 [首层任务](docs/quests.md)。

六域星盘（天赋）：战斗内按 P 打开，或 [直接打开](http://127.0.0.1:5291/?view=battle&panel=talents)。
- **结构：** 约 690 个节点，流放之路式有机大盘，包括 634 个小天赋、44 个核心天赋和 12 个基石。节点团（轮盘、弧形、星簇、基石等）由泊松分布撒开，团内节点沿圆弧轨道排列，团与团之间由穿插属性节点的路网相连，存在多条路线和环路。六个领域（寒霜、雷霆、烈焰、蚀毒、铁血、灵契）之间穿插六个过渡主题（弹幕、元素调和、法域、嗜血、迅影、灵能护盾）。
- **基石：** 每个领域两个，都带明确代价（显示为红色）。
- **规则：** 全部节点都是现有词条，经由规则引擎正常聚合。
- **天赋点：** 每级 2 点，另有任务奖励。
- **操作：** 左键点亮，远处节点会沿最短路线自动点亮；右键退点。
- **数据：** 由 `node scripts/create-talent-tree.mjs`（即 `npm run build:talents-layout`）生成到 `Content/Rules/Talents/constellation.json`，生成时校验词条参数、连线交叉、节点间距和连线是否穿过节点；`--seed N` 可换一种随机布局。验证：`npm run test:talents`。设计说明见 [progression.md](docs/progression.md)。




异常地面与旋风染色（Opus 5291）：[旋风·四色染地](http://127.0.0.1:5291/?bd=whirlwind_grounds)。命中可生成燃烧、冰缓、感电、毒性与镜像五种地面，技能聚合独立的「接触地面」和「地面染色」。镜像在每次进入时复制投射物，原体与复制体都须退出再进入；复制继承剩余寿命。其他四种地面继续正常伤害或施加异常。见 [地面说明](docs/abnormal-grounds.md)。

满屏旋风（Opus 5291）：[旋风·风暴群](http://127.0.0.1:5291/?bd=whirlwind_swarm)。已移除定时自动旋风及旧装备的 interval_whirlwind 词条。一次手动施放5枚旋风，通过镜像地面进出复制增长；先用第二槽「回响」再施放旋风，可完整执行两次共10枚。回响主动独立冷却5秒、临时状态5秒，下次手动技能通过 consume_status 消耗状态并复施一次。九件装备、部位词条池和十阶数值保持有效。见 [当前研究](docs/whirlwind-swarm-research.md)。

旋风预览（Opus Studio 5291）：打开 `http://127.0.0.1:5291/?bd=whirlwind_return`，一键应用「游走旋风」。普通T1回风之杖绑定「创建旋风 + 投射物随机游走」；基础速度27米/秒，约每0.45至0.75秒随机转向，碰壁或到达12米活动边界折返，基础持续2秒。`emit` 创建真实载体，共享投射物扫掠碰撞、命中事件、数量、增伤、速度、存在时间和半径词条。命中后继续飞行，同目标最短间隔0.5秒（可由既有词条缩短），同批命中上限和伤害衰减仍生效。运动复用 `engine/combat/area-roaming.mjs`，独立 `public/prefabs/whirlwind.mjs` 只显示实际载体位置，最多显示48个持续特效。主动位于 WebTraits/WebBuilds；`node scripts/create-whirlwind-preview.mjs` 重建预设，`node --test tests/whirlwind.test.mjs` 验证移动、边界、投射词条与命中。

## 启动

运行 `Start-RuleStudio.bat` 或 `Start.ps1`，打开 http://127.0.0.1:5291/ 。需要 Node 22；Vue、Three.js 已随工具保存，不需要安装前端依赖。

`npm test` 运行全部当前测试。`deploy/start-public.ps1` 复用现有腾讯云SSH隧道；公网入口 http://43.139.72.98:5590/ 依赖本机服务与隧道保持运行。默认自动选择本机网卡，可显式传入 BindAddress。服务仅监听本机，写入规则前完整校验。

## 已恢复的网站功能

特性族 →「词缀分类」展示攻击型、防御型、特殊型的完整结果，支持搜索、范围/特性族筛选、分页和分类依据。用途元数据保存在 `Content/Rules/Tags/affix_categories.json`；`/?view=affix-categories` 可直达。网站上层的部位映射表为 `public/data/equipment-drop-categories.json`：胸甲/鞋子/腰带仅防御型，武器/手套为攻击型+特殊型，戒指/护符仅特殊型；头盔/副手沿用完整池。`public/equipment-generation.mjs` 在掉落、商店与鉴定时查表筛选候选池；`public/equipment-crafting.mjs` 让三档灵石洗炼、陨星石重置及增缀共用此限制，预兆进一步与部位池取交集，洗炼台计数和战斗预兆图鉴同步。没有可用且不冲突的候选时不扣材料、不改装备。固定基底、传奇词缀和未选中的已有词缀保留。规则引擎不读取该表。

同页可按前缀/后缀交叉筛选。前缀侧重能力来源与收益：基础属性、直接伤害/防护、条件数值成长、直接回复量、技能授予与直接事件触发；后缀侧重运行方式与效率：累计/资源/时间触发门槛、触发编排、回复效率、资源支付、控制和弹道行为。全量目录与实际可洗炼池均接近各半。归属及依据写入网站上层的 `public/data/affix-positions.json`，每条恰好一种归属；不添加装备前后缀配额限制，也不改变掉落和洗炼。`node scripts/classify-affix-positions.mjs` 补齐新条目并保留已有人工划分。

游戏内构筑图鉴：3D 战斗 → 右侧「可用 BD」，或左侧「构筑原理与词条追求」。使用现有 HUD 的金边浮窗，左侧切换真实 BD，霜雷交响提供原理、词条追求、装备参考三页签；T1/T5/T10 参考值读取当前规则，装备读取现有预设，传奇戒指单独展示。一键应用复用既有预设流程；浏览不修改物品或规则。`/?bd=synergy_rime_thunder` 可直接打开游戏内面板，旧 `/builds.html` 转入游戏。

BD Hunter 独立分析页：`/bdhunter.html`，侧栏「运行与验证」可打开。默认分析霜雷交响的词缀移除与合法同槽替换；单体、群体、高抗和固定压力分别对照。方法与命令行见 [BD Hunter](docs/bd-hunter.md)。

## 规则与数据归属

- `Content/Rules` 是技能、装备、物品、怪物、状态、特性族和十阶数值的共享数据源；`Content/Rules/Presets` 是体验BD目录，服务通过 `/presets/` 读取，不再维护 public 内第二份。
- 技能等于已有特性的聚合。例如冰锥术引用“创建冰锥”和“冰缓”两个特性；附加特性按父子依赖启用。装备实例和阶级生成在上层完成，战斗仍读取同一聚合计划。
- 制作约定见 [trait-spec.md](docs/trait-spec.md)，词条表见 [combat-affix-table.md](docs/combat-affix-table.md)，装备基底见 [equipment-bases.md](docs/equipment-bases.md)。
