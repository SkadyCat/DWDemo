# DWDemo

网页版 ARPG：3D 地牢 + 词条驱动的构筑。全部玩法跑在新规则引擎 `CustomTools/RuleStudio/core/` 上，任何流派都只靠词条组合实现。

## 启动

需要 Node.js 22 或更新版本。

- macOS：双击根目录的 `Start-Game.command`。
- 命令行：`npm start`，然后打开 http://127.0.0.1:5291/ 。

游戏里左上角「更新到最新」会拉取最新提交并刷新。

## 玩法

- **营地**：选地图 T 阶（T1–T16）和地图类型，看「本图要求」是否达标；换装、洗炼、选技能；「流派」页可以一键换上十一个示范流派任意阶段的整套装备。
- **路石**：开地图要放入一块路石（T 阶不低于节点，开图时消耗；魔法 / 稀有路石带地图词缀，阶更高时按路石的阶打）。首领必掉路石，精英偶尔掉落；营地旁的 T1 节点免费。营地的「地图装置」列出全部路石。
- **UE 版规则引擎**：移植指南见 `CustomTools/RuleStudio/docs/ue-rule-engine-port.md`（写给接手的 session：架构、逐模块对照、确定性与金样测试、里程碑）。
- **账号**：打开游戏先选账号，每个账号一份独立存档，存在 `CustomTools/RuleStudio/data/accounts/`（不进 git）。想从头开始就「新建账号 · 全新开始」，旧号原样保留；营地右上角「账号 · 名字」切回选择界面。第一次可以用「带上本机存档」把浏览器里原有的进度放进新账号。删除的账号移到 `data/accounts/.trash/`，手动拷回即可恢复。
- **内容编辑器**（营地右上角「内容编辑器」，或打开 `/editor/`）：装备基底、传奇、特性与词条、通货、地图词缀、技能、召唤物、状态、怪物类型、怪物技能、精英词缀、地图类型全部以卡片展示；点卡片在右侧改字段，保存写入 `CustomTools/RuleStudio/data/overrides.json`，回到游戏刷新即生效。可以还原单项或整条，也可以复制出新条目。测试和报告默认用原始数据，设 `DW_OVERRIDES=1` 才带上改动。
- **天赋盘**（右侧菜单「天赋」，快捷键 P）：六域星盘，259 个点。小点是数值，大点是两条数值；六边形的特性点把形态 / 联动特性固定在盘上（如点燃扩散、击杀爆炸、碎冰、雷链、穿透、风眼）；每域外缘和域与域之间的桥上共 12 个基石（核心特性）。点亮必须与已点亮的点相连，可随时取消（不能断开其他点）。天赋点：每打通一个图集节点 +1，首领要塞 +2。
- **图集**（右侧菜单「地图」，快捷键 M）：一张星图（约 130 个节点，五个地区，越往外 T 阶越高）。打通一个节点，和它有路相连的节点开放；首领要塞、宝库、腐化、试炼节点各有修正。拖动平移，滚轮缩放。
- **地图**：WASD 移动，鼠标瞄准，按住左键施放当前技能，1–4 切换技能。打倒首领即通关。掉落在地上显示名牌（按稀有度上色，堆叠时自动错开），点名牌走过去拾取，通货走过即拾；普通白装默认隐藏，按住 Alt 显示。离开地图时剩下的掉落一并收进背包。
- **装备**：10 个部位，每件 3 条基底 + 至多 6 条随机词条。基底第 1 条可能是主动技能（武器必带），其余是**特性**——从通用特性池（形态 / 联动 / 核心）随机，改变技能的形态与连锁；一身装备 20 多条特性就是一个 BD。随机词条只出攻击与防御数值。
- **质变与清屏**：十一个示范流派各有五级质变阶梯（角色面板里能看到点亮到哪一级）；地图杂兵成群出现，连杀与「清屏」会在画面上提示。
- **洗炼**：随机词条用魔晶（加一条）、混沌石（重洗）、灵石（升 T）、无效石（删一条）；封印符保留选中的一条；特性用淬火石（升 T）和三种精华（重铸为指定层的特性）；技能石重铸主动技能。

## 目录

- `CustomTools/RuleStudio/core/`：规则引擎（见其中 README）与内容（词条族、技能、地图压力、十一个流派、装备）。
- `CustomTools/RuleStudio/public/game/`：游戏页、3D 画面、特效桥、存档。
- `CustomTools/RuleStudio/public/vfx/`：特效系统——程序化贴图集、GPU 实例化粒子、地面冲击环与印记、刀光、闪电、动态光源、HDR 后期（泛光、冲击波折射、色差、镜头震动）与各元素的特效配方；`/vfx/index.html` 是特效实验室，可逐个播放。`public/prefabs/` 只剩地牢地面、传送门和掉落标记。
- `CustomTools/RuleStudio/tests/`：引擎单元测试、16 个验收流派、十一个流派的分阶段验证。
- `CustomTools/RuleStudio/scripts/`：校准与报告脚本（`core-calibrate-all.sh`、`core-roles.mjs`、`core-usefulness.mjs`、`core-archetype-report.mjs`）。
